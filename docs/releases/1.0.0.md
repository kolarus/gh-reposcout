The first release of RepoScout: search GitHub repositories, open their details, and save them for offline use.

**Which APK?**

- `RepoScout-<version>-arm64-v8a.apk`: for phones. Smaller, and fits virtually every Android phone from the last several years.
- `RepoScout-<version>-universal.apk`: every CPU type, including emulators. Use it if the other one won't install.

Both need Android 7.0 or newer. They're signed with the project's release key, so later versions install over this one.

**What's in it**

- Search as you type, sorted by best match, stars or last update, with pull to refresh and recent searches.
- Details: stats, topics, website and the owner's profile; open on GitHub or share.
- Save repositories for offline use, avatars included.
- GitHub's rate limits handled in the app: a countdown, and searches resume by themselves.
- Light, dark or system theme, and `reposcout://repo/{owner}/{name}` deep links.

**Check the download** before installing: the checksums in `SHA256SUMS.txt`, the build's provenance and the signing certificate. The steps are in the README, under "Install".
